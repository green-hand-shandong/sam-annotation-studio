## 二、设计说明（说明书第一部分）

### 2.1 系统架构

系统采用三层 B/S 架构：

1. **表现层**（web/）：React 18 + TypeScript + Tailwind CSS，Canvas 2D 标注交互，hash 路由单页应用；构建产物由后端静态服务，一体机单进程部署
2. **业务层**（backend/routers/）：FastAPI 异步框架，8 个路由模块，SQLite（WAL 模式）持久化，HMAC-SHA256 签名 Token 认证，基于角色的访问控制
3. **推理层**（backend/services/inference.py）：torch_npu 推理服务，模型懒加载常驻；复用 ascend310p_compat 兼容层解决 310P 平台 SDPA 融合算子缺失、bicubic 插值 kernel 缺失、激活函数非连续输入拒绝等适配问题

### 2.2 核心技术点（源代码说明书的技术特色）

1. **NPU 交互式分割流水线**：SAM ViT-H 在昇腾 310P 上的完整推理链路——点/框提示编码 → ViT 图像编码 → mask decoder → 3 候选 mask + IoU 质量预测 → 最优掩码双线性上采样回原图分辨率 → PNG 编码返回
2. **文本提示批量预标注**：SAM3 检测器一次前向输出全图所有匹配实例（DETR 风格），自动生成标注（source=sam3）进入待复核队列，人工只需复核修正
3. **掩码存储与格式转换**：标注掩码以原图分辨率单通道 PNG（base64）存储；导出时 OpenCV 轮廓提取（RETR_EXTERNAL + TC89KCOS 多边形近似）生成 COCO segmentation 多边形、未压缩 RLE、YOLO 归一化多边形、LabelMe shapes 四种格式
4. **审核工作流**：标注（待审核）→ 审核员通过（留痕）/ 驳回（删除并记录原因），任务状态机：进行中 → 待审核 → 已完成，支持重开

### 2.3 数据库设计

6 张表：users（用户）、datasets（数据集）、images（图片）、tasks（任务）、annotations（标注，含掩码 PNG/边界框/分数/来源/审核状态）、logs（操作日志）、exports（导出记录）。

## 三、操作说明书（说明书第二部分，配界面截图）

### 3.1 登录
访问系统地址，输入用户名密码。三种内置角色：管理员（全部权限）、标注员（标注）、审核员（审核）。

### 3.2 数据集管理
新建数据集 → 上传图片（支持 zip 包与多选）或从服务器路径批量导入（大数据集免上传）→ 列表显示图片数量。

### 3.3 创建标注任务
填写任务名、选择数据集、设置类别（如 lesion,object），创建后进入标注工作台。

### 3.4 智能标注（核心操作）
1. 左侧选择图片
2. **点选模式**：左键点目标（前景，绿点），Alt+点背景（红点）；**框选模式**：拖拽矩形框住目标
3. 点击「生成分割」（或 Enter），SAM 在 NPU 上生成掩码（叠加显示，绿色半透明）
4. 选择对象类别，点击「保存标注」（或 S），掩码与边界框入库
5. 可对未标注图片执行「批量预标注」：输入文字（如 lesion），SAM3 自动生成标注

### 3.5 质量审核
审核员查看待审核列表（含掩码预览），逐条通过或驳回（填原因）。驳回的标注自动删除并留痕。

### 3.6 数据导出
选择任务与格式（COCO JSON / YOLO Segmentation / LabelMe）→ 导出打包下载；历史记录可重复下载。

### 3.7 模型与设备
查看 NPU 设备状态、显存占用、已加载模型与系统版本。
